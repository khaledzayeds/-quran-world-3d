# Quran World 3D

First playable prototype of a Quran-inspired 3D exploration world.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Deploy to Cloudflare Pages with build command `npm run build` and output directory `dist`.

This prototype has a simple placeholder avatar and world. Quran reading, accounts, saving progress and advanced avatar assets are planned for later phases.
